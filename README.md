# INVENTORY — Система учёта мебели для предприятий

Комплексная система учёта мебели для образовательных учреждений, обеспечивающая эффективное управление материальными активами, контроль состояния, перемещений и ремонтов мебели.

## 📌 Цель проекта

Оптимизация расходов и повышение прозрачности использования бюджетных средств через автоматизацию учёта мебели в школах, вузах, колледжах, техникумах и административных зданиях образования.

## 🎯 Область применения

- Школы, лицеи, гимназии  
- Высшие учебные заведения (университеты, колледжи)  
- Техникумы и профессиональные училища  
- Дошкольные образовательные учреждения  
- Административные здания образовательных учреждений  

## ✨ Основные функции

### Реестр мебели
- Уникальный инвентарный номер для каждого предмета  
- Подробная информация: тип, модель, производитель, дата приобретения  
- Фиксация стоимости (покупка и остаточная)  
- Привязка к помещению (корпус, этаж, кабинет)  
- Загрузка фотографий  
- Генерация и печать QR-кодов  

### Управление состоянием
- Отслеживание состояния: новое, хорошее, удовлетворительное, требует ремонта, списано  
- Журнал технического состояния  
- Планирование и учёт ремонтов  
- Фиксация причин списания  
- Уведомления о необходимости обслуживания  

### Поиск и фильтрация
- По инвентарному номеру, QR-коду, серийному номеру  
- Фильтры по типу, местоположению, состоянию, поставщику, дате поступления  
- Расширенные фильтры по стоимости и сроку эксплуатации  

### Управление ролями и доступом
- **Администратор** — полный доступ  
- **Материально-ответственное лицо** — управление в своих помещениях  
- **Бухгалтер** — финансы и отчёты  
- **Технический персонал** — ремонты и состояние  
- Настраиваемые права  

### Мобильное приложение и веб-интерфейс
- Адаптивный веб-интерфейс  
- Нативные приложения для iOS и Android  
- Сканирование QR-кодов через камеру  
- Добавление фото, изменения в реальном времени  
- **Офлайн-режим** с синхронизацией при подключении

## 🗂 База данных и справочники

### Основные справочники
- **Тип мебели** (стол ученический, стул, парта, шкаф, стеллаж, доска, кресло, тумба)  
- **Состояние** (новое, хорошее, удовлетворительное, требует ремонта, списано)  
- **Корпус** (главный корпус, корпус №1 и т.д.)  
- **Кабинет** (101, 201, актовый зал, спортзал, библиотека)  
- **Поставщик**  

### Карточка мебели (основные поля)
- Инвентарный номер (уникальный, обязательный)  
- Серийный номер, тип мебели, модель  
- Дата поступления, стоимость приобретения, остаточная стоимость  
- Поставщик, корпус, кабинет, состояние  
- Фото, QR-код (генерируется автоматически)  
- История перемещений, журнал ремонтов  
- Ответственное лицо, примечания  

### История перемещений
- Дата перемещения, источник и назначение (корпус/кабинет)  
- Основание, инициатор  

### Журнал ремонтов
- Даты начала и окончания, описание проблемы, выполненные работы  
- Стоимость ремонта, исполнитель, статус (запланирован, в работе, завершён)
